01. Project & Architectural Overview

Agent-Passport is a state-of-the-art **Zero-Standing-Privilege (ZSP)** identity and security governance middleware designed specifically for multi-agent AI ecosystems.

AI agents running autonomous workflows often require access to host resources (filesystems, shells, and web search APIs). If an agent is compromised via a prompt injection attack, standing keys or execution permissions can be permanently hijacked. Agent-Passport solves this by removing all standing credentials from the agent, enforcing real-time checkout validation, and intercepting direct tool calls.

🛡️ ZSP Registry

In-memory registry that issues time-restricted, single-use passport tokens (TTL) for approved commands.

🔗 Runtime Hook

Overrides Node's core spawn systems at runtime, blocking direct command executions bypassing the gateway.

🧩 MCP Gateway

An Express server acting as a secure gateway verifying hash chains, rate bounds, and payload content.

03. The Security & Coding Pillars

To understand this project in-depth, learn about these five core pillars:

1. Zero-Standing-Privilege (ZSP)

ZSP is the design pattern of **never granting permanent permissions**. When the simulation requestor agent attempts to run a file search, it does not possess the execution keys. It makes a POST request to `/mcp/checkout`. The server validates policies and returns an ephemeral (e.g., 5-second) token. The agent must present this token at `/mcp/execute`. Once validated and used, it vanishes.

2. Process-Level Monkey Patching (Hooks)

To catch rogue agents attempting direct tool calls, we intercept executions. In Javascript, this is accomplished by monkey-patching: 

// Example monkey patching hook
const originalSpawn = require('child_process').spawn;
require('child_process').spawn = function(cmd, args, options) {
  if (!options || !options.env || !options.env.GATEWAY_TOKEN) {
    throw new Error("SECURITY EXCEPTION: Direct spawn blocked by Antigravity Hook!");
  }
  return originalSpawn(cmd, args, options);
};

3. Command Injection & Path Traversal Containment

Agents must be prevented from traversing out of their workspace (e.g. using `../../`). The Governance agent resolves paths dynamically: 

// Path Containment check
const path = require('path');
function validatePath(targetPath, workspaceRoot) {
  const resolved = path.resolve(targetPath);
  return resolved.startsWith(path.resolve(workspaceRoot));
}

4. WebSockets for Live Telemetry

Dashboard notifications and topology flow lines are driven by full-duplex WebSocket connections. The backend pushes updates (type: `registry_update`, `threat_alert`, `request_pulse`) instantly, avoiding server polling and maintaining dashboard responsiveness.

5. 2D HTML5 Canvas Animation & Physics

Instead of standard DOM overlays, the topology grid runs on HTML5 Canvas. The coordinate translations handle drag-panning and scroll-wheel scaling zoom. A warping math formula calculated inside `requestAnimationFrame` creates dynamic grid deformations around the user's cursor.

04. Exposing via Public URL & Free Hosting

To share your dashboard live with judges or other teams, you need a public URL. You can deploy it permanently for free on **Hugging Face Spaces** or use temporary local tunnels.

🚀 Method A: Free Permanent Hosting on Hugging Face Spaces (Recommended)

Hugging Face Spaces allows you to host full-stack apps inside a Docker container for free. Because we configured our backend to serve the static frontend on a single port (port 7860 on HF) and enabled dynamic address resolution, the app will deploy automatically with a permanent HTTPS link.

Step 1: Create a Hugging Face Space

Go to huggingface.co/new-space. Choose a name, select Docker as the SDK, and choose Blank as the template. Keep the space public.

Step 2: Check the Root Dockerfile

We created a root Dockerfile at the base of your project. It compiles your frontend code, copies the static build into the backend assets directory, and launches Express on port 7860. The file contents are:

# Build Stage for Frontend
FROM node:20-alpine AS frontend-builder
WORKDIR /frontend
COPY frontend/package*.json ./
RUN npm install
COPY frontend/ .
RUN npm run build

# Final Run Stage
FROM node:20-alpine
WORKDIR /app
COPY backend/package*.json ./
RUN npm install --production
COPY backend/ .
COPY --from=frontend-builder /frontend/dist ./frontend/dist
ENV PORT=7860
EXPOSE 7860
CMD ["npm", "start"]

Step 3: Push Files to Hugging Face

Initialize a Git repository inside your capstone folder and push all files directly to your Hugging Face Space repository:

Hugging Face will automatically build your container and give you a permanent public URL (e.g., https://huggingface.co/spaces/username/spacename).

05. Interview Q&A Playbook

Q: Why is Zero Standing Privilege (ZSP) better than static administrative keys for AI agents?
Static administrative credentials represents a massive attack surface. If an agent is compromised via a recursive prompt injection exploit, the attacker gains full, permanent access. With ZSP, credentials are issued on-demand, limited to a specific action (e.g. read_file), and expire immediately after use. This minimizes the risk of credentials hijacking.
Q: How does the process hook actually intercept system spawns?
The process hook overrides node wrappers at runtime. Whenever a script attempts to invoke a shell command, the hook evaluates the environment parameters. If it doesn't detect a security token issued by the gateway, the hook intercepts the stream, halts execution, and reports a critical threat payload event.
Q: What happens if an agent attempts directory traversal (e.g. `../../etc/passwd`)?
The Governance evaluation parses path strings using resolve metrics. If the resolved path points outside the designated workspace path boundary, the authorization fails, the checkout is rejected, and a governance violation alert is broadcast.
Q: Why draw the network topology in canvas instead of D3 or React-Flow?
Performance. Rending particle streams and cursor-warp grid deformations at 60 FPS in SVG or DOM elements creates significant lagging. Direct 2D Canvas rendering has near-zero overhead and can handle rich shadow glows smoothly.
